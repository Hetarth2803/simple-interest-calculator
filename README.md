# Simple Interest Calculator

A Bash script that calculates simple interest based on user input.

## Description
This calculator computes simple interest using the formula:

Simple Interest = (Principal x Rate x Time) / 100

## Input Fields
- **Principal**: the initial amount of money
- **Rate of interest**: the annual interest rate (in %)
- **Time period**: the duration in years

## Usage
1. Run the script: `bash simple-interest.sh`
2. Enter the principal, rate of interest, and time period when prompted.
3. The script prints the simple interest.
